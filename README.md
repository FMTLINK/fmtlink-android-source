# FMTLINK для Android — исходный код выпусков / release source code

**RU.** Здесь публикуется полный соответствующий исходный код каждого выпуска
приложения FMTLINK для Android (GNU GPL-3.0 §6(d)). Исходники лежат не в ветке,
а в **архиве каждого release**: https://github.com/FMTLINK/fmtlink-android-source/releases

Tag'и этого репозитория (`v<версия>`, например `v0.2.0-public-pilot.4`)
указывают на служебный коммит с этим README. Исходный код версии — в архиве
её release; коммит, из которого он собран, назван в описании release и в
`SOURCE-INFO.txt` (для `v0.2.0-public-pilot.4` это `FMTLINK/fmtlink-android@2225ccc`).
Одноимённый tag в репозитории разработки FMTLINK/fmtlink-android — другой tag.

APK как объединённая работа распространяется на условиях GPL-3.0-or-later
([COPYING](COPYING)); файлы FMTLINK — Apache-2.0 (`LICENSE` в архиве). Как
собрать — `BUILD-FROM-SOURCE.md` в архиве. FMTLINK не связан с проектом
sing-box и не одобрен его авторами.

**EN.** This repository publishes the complete corresponding source of each
FMTLINK for Android release (GNU GPL-3.0 §6(d)). The source is in the
**archive attached to each release**, not in a branch. Tags here (`v<version>`)
point to a service commit containing this README; the source commit of each
version is named in its release notes and `SOURCE-INFO.txt`. A tag with the
same name in FMTLINK/fmtlink-android is a different tag. The APK as a combined
work is GPL-3.0-or-later ([COPYING](COPYING)); FMTLINK files are Apache-2.0.
FMTLINK is not affiliated with or endorsed by the sing-box project or its
authors.
